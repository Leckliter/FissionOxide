# Parity batch: ui-toolbar-tooltips

Make FissionOxide match Autodesk Fusion for each item below. Each item says what Fusion
does, what FissionOxide does now, and where to start. Keep changes scoped to these items, add tests
where the behaviour is testable, and run `cargo test` and `cargo clippy` before opening the PR.

Observed on 2026-10-21 (prober 7) by hovering every SOLID ribbon button for 1 s and then 4 s in
each app; Fusion's window was 907 px wide (its ribbon in the responsive state: CREATE 5, MODIFY 4),
FissionOxide's 1002 px wide, built from `main` at `42dec181`. The existing rows
`ui:toolbar:rich-tooltip` (the expansion exists) and `ui:menus:tooltip-style` (dropdown row tooltips)
stay verified; these items are the ribbon button tooltip's look, timing, texts and illustration.

## ribbon tooltip style (P1)
- key: `ui:toolbar:tooltip-style`
- Fusion: After about 1 s a dark grey rounded panel (white bold title, light grey body text) opens under the button with its left edge at the button's left edge. The title carries the shortcut in parentheses ("Extrude (E)", "Hole (H)", "Press Pull (Q)", "Fillet (F)", "Measure (I)"; "Revolve", "Shell" and "Combine" have none), then a description paragraph and a usage paragraph ("Select an extrusion type, select sketch profiles or faces to extrude, then specify ...") at once. The panel may extend past the window's right edge (Select, Insert Mesh).
- FissionOxide: A light panel with dark text: bold "Extrude", one description line "Adds depth to a closed sketch profile or a planar face.", then a grey "Shortcut: E" line; no usage paragraph until the expansion.
- Start here: `crates/ui/src/menus.rs:1265` (`on_hover_ui` for a ribbon button: the title, blurb and `Shortcut:` line), `crates/ui/src/theme.rs` (a dark tooltip frame like the dropdown rows already use, `ui:menus:tooltip-style`).

## ribbon tooltip expansion (P1)
- key: `ui:toolbar:tooltip-expanded-illustration`
- Fusion: About 3 s later the same panel grows downward with a large illustration (a rendered picture of the command's result, about 190 px tall, light grey frame) and the line "Press Ctrl+/ for more help." under it. Commands with no illustration (Display Configuration Table, Offset Plane, Add To Assembly) show the help line at once and never grow.
- FissionOxide: The expansion adds the command's own ribbon icon at the left and a usage paragraph ("Pick profiles or faces, then drag the arrow or type the distance ...") and no help line.
- Start here: `crates/ui/src/menus.rs:1265` (the expanded part of the hover ui), `crates/ui/src/tips.rs:866` (per-command texts; add an illustration slot per command and a help line), `crates/ui/src/icons.rs` (illustrations could be larger painted icons until pictures exist).
