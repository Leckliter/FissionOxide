# Parity batch: ui-solid-dialogs

Make FissionOxide match Autodesk Fusion for each item below. Each item says what Fusion
does, what FissionOxide does now, and where to start. Keep changes scoped to these items, add tests
where the behaviour is testable, and run `cargo test` and `cargo clippy` before opening the PR.

## solid modify dialogs (P1)
- key: `ui:dialogs:solid-modify-dialogs`
- Fusion: SOLID dialogs: DRAFT (Type: fixed plane / parting line icons; Pull Direction (picked, defaults to a picked face); Faces; Tangent Chain; Flip Pull Direction; Draft Sides One Side/Two Sides/Symmetric; Angle with a rotator). SCALE (Entities: bodies, components or sketches; Point; Scale Type Uniform/Non-Uniform; Scale Factor, or X/Y/Z factors). SPLIT BODY (Body to Split; Splitting Tool(s): any face, plane, surface body or sketch curve; Extend Splitting Tool(s), checked). THREAD (Faces; Modeled; Full Length; Threads Library button; Thread Type, e.g. ANSI Unified Screw Threads / ISO Metric profile; Size, Designation and Class dropdowns filled from the library with Auto; Direction Right/Left hand; Remember Size; Length and Offset when not Full Length). RIB (Profile pick; Thickness Direction icons Symmetric/One side; Extent Type To Next/Depth; Flip Direction; Thickness).
- FissionOxide: THREAD: FissionOxide takes free-text 'Pitch (empty = ISO)', 'Size (M10x1.5; empty = as drawn)' and 'Class (empty = 6g / 6H)' plus a Left-handed checkbox. Fusion picks Thread Type, Size, Designation and Class from a thread library in dropdowns (Auto picks the size from the face diameter), with Full Length and Remember Size. DRAFT: FissionOxide has Faces, a Pull direction plane chosen from a list, Angle and Flip; it lacks Type, Tangent Chain and Draft Sides. SCALE: FissionOxide has Bodies, Point and Scale factor; it lacks Scale Type Non-Uniform and component/sketch entities. SPLIT BODY: FissionOxide's Splitting tool is a plane or planar face from a list; Fusion accepts any face, surface or sketch curve, with Extend Splitting Tool. RIB: FissionOxide uses a Sketch dropdown plus Lines rather than a Profile pick, and lacks the Thickness Direction choice.
- Start here: `crates/ui/src/forms.rs`, `crates/ui/src/dialogs.rs`

## create dialogs (P1)
- key: `ui:dialogs:create-dialogs`
- Fusion: CREATE dialogs: LOFT (Feature/Analysis tabs; a Profiles list (+/x), each row with an end condition (Free/Direction/Tangent/Curvature); Guide Type Rails/Centerline; a Rails list; Chain Selection; Closed; Tangent Edges Merge; Operation). SWEEP (Feature/Analysis; Type Single Path / Path + Guide Rail / Path + Guide Surface; Profile; Path; Chain Selection; Orientation Perpendicular/Parallel; then Distance, Taper Angle, Twist Angle; Operation). EMBOSS (Sketch Profiles pick; Faces; Tangent Chain; Effect Emboss/Deboss icons; then Depth, Alignment angle, horizontal/vertical distance and rotation handles on the face). PIPE (Path pick; Chain Selection; Section Circular/Square/Triangular; Hollow with Section Thickness; Distance; Operation).
- FissionOxide: LOFT: FissionOxide has Profiles, Ruled, Closed and Operation. It lacks the per-profile end conditions, Guide Type Rails/Centerline with a rails list, Chain Selection, Tangent Edges Merge, and the Analysis tab. SWEEP: FissionOxide has Profile, Path and Operation. It lacks Type (path plus guide rail or surface), Orientation, Distance, Taper Angle and Twist Angle. EMBOSS: FissionOxide picks a Sketch from a dropdown and has a 'Deboss' checkbox; Fusion picks profiles directly and uses Effect icons. PIPE: FissionOxide uses a 'Path sketch' dropdown plus curves; Fusion picks the path in the canvas with Chain Selection and a Hollow checkbox. Check the engine supports each option before adding UI, and file engine gaps with the ledger entries (api:loftFeatures, api:sweepFeatures, api:embossFeatures, api:pipeFeatures).
- Start here: `crates/ui/src/dialogs.rs`, `crates/ui/src/forms.rs`
