# Fusion vs FissionOxide: reference cases

Generated by `py tools/fusion-bridge/client.py compare`. Each case is built in Fusion from recipe.json and in FissionOxide from part.jsonl.

- **match**: same bodies, volume, area, bounding box, centre of mass and face count.
- **match-geometry**: the same solid, but split into a different number of faces.
- **disputed**: FissionOxide agrees with expected.json but Fusion doesn't. Check the Fusion runner before blaming either app.
- **mismatch**: FissionOxide differs from Fusion. This is a parity bug.
- **fusion-unbuilt**: the bridge couldn't build the recipe in Fusion (an unsupported op, or a runner error).
