# Parity run, 2026-10-21: Fusion vs FissionOxide, hands-on

Autodesk Fusion (Personal, 2705.x) and FissionOxide (`main` at `1f7c4f8`, `target/release`
build of 2026-10-20 23:41) were driven side by side on the 1920x1080 display with desktop
control. Both ran the same session: new design, Create Sketch on the ground plane, a dimensioned
rectangle typed as `40 Tab 20 Enter` (`2 Tab 1 Enter` in Fusion, which was in inches), Finish
Sketch, Extrude, Fillet of the top face, then every toolbar tab, the panel dropdowns, the File,
workspace, Help and profile menus, the marking menu on empty canvas, a face and an edge, the S
key, the browser rows and their menus, the timeline, the ViewCube and its menu, the navigation
bar flyouts, and Preferences.

This builds on `parity/reports/2026-10-20.md` and `parity/ui-features.jsonl`. Everything the
earlier runs marked verified and that this session touched still matches (ViewCube hot spots and
menu, camera animation, heads-up Tab input, marking-menu ring and overflow, browser body and
sketch menus, timeline menu and drag, Help menu, Design Shortcuts, Display Settings, Grid and
Snaps, Measure, Preferences presence). This report lists only what differs, with a code pointer
each, and the new batches in `parity/batches/` that carry them.

## What matched in the core workflow

- Create Sketch highlights the ribbon button and shows the three origin planes; hovering a plane
  darkens it and the cursor prompt reads "Select a plane or planar face".
- Entering the sketch animates to the plane, switches to the SKETCH tab, opens the Sketch
  Palette with Fusion's rows, and shows the Unsaved banner.
- `R`, click, `40 Tab 20 Enter` makes a 40 x 20 rectangle with both dimensions drawn with
  leaders and arrows and the horizontal/vertical glyphs. Fusion's `2 Tab 1 Enter` did the same.
- Finish Sketch animates back to the 3D view and hides the sketch once Extrude consumes it.
- `E` opens EXTRUDE; typed digits go to Distance; OK makes `Body1` under Bodies with eye
  toggles; the status bar reads `1 Profile | Area: 800.00 mm^2` as Fusion's reads
  `1 Profile | Area: 2.00 in^2`.
- `F` opens FILLET; clicking a face fillets its edges with a live preview; `2 Enter` commits.
- The SOLID CREATE and MODIFY dropdowns list the same commands in the same order as Fusion.
  Every tab (SURFACE, MESH, SHEET METAL, PLASTIC, MANAGE, UTILITIES) has Fusion's panels.
- The marking menu ring has Fusion's eight slots and swaps Fillet/Chamfer in on an edge; the
  edge list, timeline menu, body menu, sketch menu, Named Views menu, Orbit/Fit/Grid flyouts,
  the ViewCube menu and the Design Shortcuts box all match or exceed the 10-20 ledger.
- Help, profile, notifications, ViewCube and Assistant-tab clicks all work (see the retraction
  below for why they looked broken for an hour).

## P1 differences

### 1. Command dialogs keep a stale position instead of docking top-right
- **Fusion:** every command dialog opens docked at the viewport's top-right corner, whatever
  the window size, and Edit Feature does the same.
- **FissionOxide:** after the window was maximised, CREATE SKETCH, EXTRUDE and FILLET all
  opened at window position (472, 265), in the middle of the canvas over the model. egui keeps
  the Area's last position; the dialog is only placed with `default_pos` once per id. Clicking
  the profile for Extrude hit the dialog's Direction dropdown instead.
- **Start here:** [dialogs.rs:1967](../../crates/ui/src/dialogs.rs) (`default_pos` on the
  `feature-dialog` Area). Reset the Area's stored position when a dialog opens and re-dock when
  `app.canvas` changes size.

### 2. No floating value box or radius arrow for features
- **Fusion:** as soon as Extrude has a profile, a blue distance arrow, a circular taper handle
  and a floating value box (`0.00 in` with a ⋮ menu) appear at the manipulator; the box has
  focus, so typing goes there and the dialog's Distance row mirrors it. Fillet shows a radius
  arrow on the picked edges and the same box.
- **FissionOxide:** typed digits do reach the dialog's Distance/Radius field (good), but there
  is no floating box, no fillet arrow and no taper handle; the extrude arrow is a small
  triangle.
- **Start here:** [dialogs.rs:1696](../../crates/ui/src/dialogs.rs) (`Dialog::manipulator`),
  the HUD box in [viewport.rs:2365](../../crates/ui/src/viewport.rs) which already draws a
  focused floating `TextEdit` for sketches and can be reused.

### 3. No cursor prompts during commands
- **Fusion:** a tooltip follows the cursor with the current step: "Place first corner",
  "Specify size of rectangle", "Select sketch profiles or planar faces to extrude", "Specify
  distance and taper angle", "Hold Ctrl to modify selection", "Select edges, faces, or
  features to fillet", "Specify fillet radius".
- **FissionOxide:** only Create Sketch has a cursor prompt
  ([dialogs.rs:25](../../crates/ui/src/dialogs.rs), `PICK_PLANE_HINT`). Everything else is a
  lower-left status hint such as "Rectangle: click two corners"
  ([viewport.rs:2499](../../crates/ui/src/viewport.rs)).
- **Start here:** generalise the PickPlane tooltip into a per-dialog/per-tool prompt table and
  draw it with `show_tooltip_at_pointer` while the command runs.

### 4. Origin planes are three times too big
- **Fusion:** Create Sketch draws the three planes as small squares, about twice the ViewCube's
  size, centred on the origin with a small coloured axis triad.
- **FissionOxide:** the squares fill most of the viewport (in a half-width window they reach
  the edges), overlap each other, and make the ground plane hard to pick.
- **Start here:** `plane_half_size` and `plane_square` in
  [viewport.rs:2620](../../crates/ui/src/viewport.rs) and the plane drawing in
  [scene.rs](../../crates/engine/src/scene.rs). Size them from the camera distance so they stay
  about 120 px on screen.

### 5. The marking-menu ring moves away from the cursor
- **Fusion:** the ring is always centred on the click. When the list does not fit below, it
  flips above the ring (seen on a right-click at y = 600 of 790).
- **FissionOxide:** the whole menu is shifted up so the list fits below: a click at (900, 600)
  put the ring at (900, 448), a click at (650, 300) put it at (650, 208). Marking menus depend
  on the slot directions relative to the cursor, so the ring must not move.
- **Start here:** [marking.rs:732-772](../../crates/ui/src/marking.rs) (ring placement and
  `clamp`). Keep the ring at the pointer and place the list above when there is no room below.

### 6. The face list is padded with navigation and recent commands
- **Fusion:** right-click on a face lists OK, Cancel, Create Selection Set, Create Sketch,
  Extrude E, Offset Plane, Shell, Edit Feature, Edit Profile Sketch, Appearance A, Texture Map
  Controls, Properties, Show/Hide V, Selectable/Unselectable, Find in Browser, Find in Window.
- **FissionOxide:** the face list starts right (Create Sketch ... Find in Window) and then
  appends Pan, Zoom, Constrained Orbit, Fit, Home View, Remove, Show All, Hide All Bodies,
  Measure, Workspace and the recent commands, so Extrude and Create Sketch appear twice and the
  list is 24 rows. The first Extrude row shows the shortcut `Q` (it runs Press Pull).
- **Start here:** [marking.rs:434-560](../../crates/ui/src/marking.rs) (`overflow_items`; the
  face branch pushes a Press Pull item labelled Extrude at line 494, then falls through to the
  generic section).

### 7. The ribbon does not collapse at narrow widths
- **Fusion:** at a 920 px window the ribbon shrinks each panel to fewer icons (CREATE 5,
  MODIFY 4) so every panel through SELECT stays on screen.
- **FissionOxide:** panels keep their full icon count; INSERT is clipped at the right edge and
  ASSEMBLE and SELECT are off-screen with no scroll.
- **Start here:** [panels.rs:759](../../crates/ui/src/panels.rs) (`toolbar`) and the panel
  width at line 1007. Drop pinned icons from the right of each panel until the row fits.

### 8. Preferences is a strip, not Fusion's dialog
- **Fusion:** a centred modal with a tree (General with API, Design, Manufacture, Electronics,
  Render, Drawing, Simulation; Tokens; Material; Graphics; Network; Data Collection; Unit and
  Value Display; Default Units; Preview Features; Compatibility), Restore Defaults, Apply, OK
  and Cancel. General alone has language, theme, graphics driver, start-up experience, default
  design type, auto-save, recovery interval, modeling orientation, tooltips, command prompt,
  default measure, mouse setup, orbit type, reverse zoom, camera pivot, ViewCube size, gestures
  and Spacebar-repeats.
- **FissionOxide:** a full-height window docked at the left of the canvas with five pages
  (General: units, orientation, Spacebar; Navigation; Design; Sketch; Graphics) and no
  OK/Cancel/Apply.
- **Start here:** [preferences.rs:390](../../crates/ui/src/preferences.rs) (`window`).

## P2 differences

### Dialogs
- **Create Sketch has a dialog.** Fusion has none; the ribbon button stays pressed and the
  cursor prompt does the asking. [dialogs.rs:2123](../../crates/ui/src/dialogs.rs)
  (`Kind::PickPlane`), [lib.rs:1149](../../crates/ui/src/lib.rs).
- **Extrude auto-fills the profile.** With Sketch1 still selected after Finish Sketch, `E`
  opened with "1 selected" and a 10 mm preview; Fusion opens with Profiles = Select, no preview,
  and shows Distance/Taper Angle only after a pick, with OK greyed until then.
  [dialogs.rs:658-673](../../crates/ui/src/dialogs.rs) (`Dialog::open`).
- **Type is text radios; dropdowns have no icons.** Fusion's Type row is two icon toggles
  (Solid/Thin) and each dropdown value has an icon. [dialogs.rs:1720](../../crates/ui/src/dialogs.rs).
- **Extrude has a Flip checkbox row** that Fusion does not have (direction flips with the arrow
  or a negative distance). [dialogs.rs:2601](../../crates/ui/src/dialogs.rs).
- **The timeline icon appears while the dialog is open.** Fusion adds it on OK.
  [dialogs.rs:2038](../../crates/ui/src/dialogs.rs) area and
  [panels.rs:2578](../../crates/ui/src/panels.rs) (`timeline_items`).
- **Fillet dialog** still lacks the Type dropdown (Fillet / Rule Fillet / Full Round Fillet),
  the per-set table with continuity (`1 Face | 0.00 in | Tangent (G1)`) and Tangency Weight,
  and has a Preview checkbox Fusion does not show (Fusion always previews).
- **Previews draw in selection blue.** Fusion previews in the body's appearance with only the
  picked faces blue. [scene.rs](../../crates/engine/src/scene.rs).

### Sketch
- **Heads-up boxes show bare numbers.** Fusion shows `2.635 in` and a lock glyph once a value
  is typed. [viewport.rs:1015](../../crates/ui/src/viewport.rs) (`hud_text`).
- **Enter keeps the Rectangle tool.** In Fusion, Enter after typed values commits and ends the
  command (SELECT becomes active); a click-drawn rectangle keeps the tool.
  [viewport.rs:2325](../../crates/ui/src/viewport.rs).
- **No Feature Options section** in the palette while a tool runs (Fusion shows the
  2-point / 3-point / center-point toggles there). [panels.rs:2207](../../crates/ui/src/panels.rs).
- **Linetype has one toggle**; Fusion has Construction and Centerline. The palette also shows
  "2 degrees of freedom · 1 profiles" (Fusion has no such line; and it should read
  "1 profile"). [panels.rs:2207-2251](../../crates/ui/src/panels.rs).
- **Grid has no axis labels.** Fusion prints coordinate values along both axes and draws an
  origin marker; FissionOxide has one grid level and no labels.
  [scene.rs:466](../../crates/engine/src/scene.rs) (`grid`).
- **Profile colours.** Outside the sketch FissionOxide shades a visible sketch's profile
  tan/orange; Fusion shades it light blue. Inside, pale yellow vs Fusion's pale blue.
  [scene.rs:18](../../crates/engine/src/scene.rs) (`PROFILE_COLOR`).
- **The "Sketching — draw with the Create tools" hint** has no Fusion counterpart.
  [lib.rs:1536](../../crates/ui/src/lib.rs).

### Canvas
- **Axis lines are always drawn.** Fusion hides the origin by default and draws no X/Y/Z
  lines; FissionOxide draws red/green/blue lines across the whole grid.
  [scene.rs:466](../../crates/engine/src/scene.rs).
- **Default body colour** is a cool grey (186, 190, 196); Fusion's is a warm light grey.
  [scene.rs:14](../../crates/engine/src/scene.rs).
- **Status dev messages.** "extrude done" / "fillet done" stay in the lower left after a
  command; Fusion shows nothing there. [dialogs.rs:2038](../../crates/ui/src/dialogs.rs).

### Browser
- **No eye on the root row or the Origin folder** (Fusion has both; Origin starts hidden).
  [panels.rs:995](../../crates/ui/src/panels.rs) (`tree_row`), 1095 (`browser_tree`).
- **Document Settings starts collapsed**; Fusion shows "Units: in, ouncemass" and
  "Part Design" expanded. [panels.rs:1129](../../crates/ui/src/panels.rs).
- **Root reads "Untitled v1"**; Fusion reads "(Unsaved)" until saved, and its tab "Untitled"
  with a lock icon. [lib.rs:589](../../crates/ui/src/lib.rs) (`title`).
- **Sketches stays expanded with Sketch1 selected after Finish Sketch**; Fusion collapses the
  folder and selects nothing (this is what makes Extrude auto-fill).
  [lib.rs:1203](../../crates/ui/src/lib.rs) (`finish_sketch`).
- **Root, Bodies, Origin and Units rows have no context menu.** Fusion: root (Add To
  Assembly, Create Drawing, Create Selection Set, Configure, Physical Material, Appearance,
  Texture Map Controls, Properties, Export, Save Copy As, Save As Mesh, History, Display Detail
  Control, Show/Hide, Show All Components, Show All Bodies, Opacity Control, Find in Window,
  Change to Direct Modeling); Bodies (New Group, Create Selection Set, Show/Hide, Show All,
  Selectable/Unselectable); Origin (Create Selection Set, Show/Hide, Show All, Show/Hide
  Planes, Show/Hide Axes, Find in Window); Units (Change Active Units).

### Toolbar and chrome
- **Sketch panels show fewer icons** (CREATE 6 / MODIFY 4 / CONSTRAINTS 8 vs Fusion's
  7 / 5 / 12) at 22 px; Fusion's are 32 px. FINISH SKETCH's hit area is only the small icon: a
  click between icon and label does nothing. [icons.rs:1966](../../crates/ui/src/icons.rs).
- **Active tab is blue text with a blue underline**; Fusion's is bold black with a black
  underline. [panels.rs:759](../../crates/ui/src/panels.rs).
- **Workspace menu** is Title Case with greyed entries; Fusion's is upper case with lock icons
  on Generative Design and Simulation, has ELECTRONICS, and DRAWING/ELECTRONICS open submenus.
  [panels.rs:57, 803](../../crates/ui/src/panels.rs).
- **File menu** lacks Add To Assembly, Upload, Save As Latest, Export... (as one item), Create
  Version, 3D Print, Capture Image, Share File Link and View Details on Web, and adds Open
  Recent, Show Data Panel, Save to File, New Drawing from Design, Insert into Design and
  Preferences. [panels.rs:204](../../crates/ui/src/panels.rs).
- **The bell opens nothing** unless an update is pending; Fusion opens a Notifications panel
  with cards and Dismiss all. [panels.rs:130](../../crates/ui/src/panels.rs),
  [updates.rs:100](../../crates/ui/src/updates.rs).
- **Undo list** shows "Fillet, Extrude, 2-Point Rectangle, Sketch" with no icons; Fusion
  shows "Undo Fillet, Undo Extrude, Undo Finish Sketch, Undo 2-Point Rectangle, Undo Create
  Sketch" with icons. [panels.rs:161](../../crates/ui/src/panels.rs).
- **COMMENTS does not expand.** Clicking the header or its chevron changes nothing; Fusion
  opens a panel. [panels.rs:2056](../../crates/ui/src/panels.rs).
- **Display Settings** lacks Environment, Graphics Preset, Ground Plane Offset and the
  Ctrl+Shift+F hint, and adds ViewCube and GPU Renderer toggles.
  [navbar.rs:156](../../crates/ui/src/navbar.rs).
- **ViewCube menu** lacks the "ViewCube Size" submenu. [viewcube.rs:571](../../crates/ui/src/viewcube.rs).
- **Timeline hover** tints the whole body; Fusion highlights only what the feature made (the
  fillet faces). [panels.rs:2578](../../crates/ui/src/panels.rs).

## Retractions: three findings that were the test rig, not FissionOxide

- **"Clicks on the right side of the window are ignored."** For an hour, Help, profile,
  notifications, the ViewCube menu and faces, the Assistant tab, a dialog's Cancel and the
  plane picks in a right-snapped window all failed, and hovering the top-right icons showed the
  OS "Close"/"Minimize" tooltips. `WindowFromPoint` showed the owner of those screen points
  was `claude.exe` (class `Chrome_WidgetWin_1`, `WS_EX_TOPMOST | WS_EX_LAYERED`) at screen rect
  1372,20..1908,748: the Claude desktop app's own window. With FissionOxide snapped to the left
  half every one of those controls worked. The 2026-10-19 notes' P0 "clicks in the top-right of
  the canvas are ignored" was almost certainly the same overlay.
- **"A dev tooltip 'Hovering, waiting, zooming in +2' shows on the canvas."** That text is not
  in the source; it was the overlay's own tooltip.
- **"Launching the exe again opens a second instance."** `Start-Process` on the running exe
  did not; the single-instance guard in `crates/desktop/src/instance.rs` works. Only the
  desktop-control tool's `open_application` (which launches with its own arguments) did.

For the next run: snap the app under test to the left half, or check `WindowFromPoint`
before calling a click failure a bug.
