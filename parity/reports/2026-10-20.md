  - Double-clicking an edge selects its loop.

- **Dialogs:**
  - Single-click hole placement, with the hole diagram.

  - Shell direction.
  - Offset Plane takes a picked face.
- **Timeline and browser:**
  - Drag the history marker; drag features to reorder.
  - Rename in place; fuller context menus for bodies, sketches, planes, components and the

- **App:**
  - Per-design units (mm, cm, m, in, ft).
  - A Change Parameters dialog with model parameters.
  - Preferences with navigation presets.

  - Measure with precision and copy; named views; an appearance panel with drag-and-drop;

## Notes for the next run

- **Installing a new build** into `C:\Program Files\FissionOxide` needs an admin prompt that only
  the user can approve, so each re-check round waits on them. A per-user installer would remove
  that wait.
- **Focus:** Windows' TextInputHost and the desktop shell often take focus between actions. The
  scratch helper `focus_fox.ps1` clicks FissionOxide's own canvas to get it back. While Chrome
  Remote Desktop is connected, its sharing bar blocks all input.
- **Modifier keys:** the desktop-control tool sends a modifier in the same frame as the click,
  and egui misses it. Hold the key with `keybd_event` instead.
- **Agent builds** need `FOX_OCCT_DIR` set to the main checkout's `target/OCCT`, plus
  `cargo test --no-fail-fast` and a temp `FOX_DATA_DIR`.

# Afternoon run, 2026-10-20: one session covering both commands and UI

This session took over from the archived driver and UI sessions. The functionality driver
(`parity_loop.py run --until-done --probes 2 --fixers 3`) and the UI prober share Fusion through
the bridge lock. Ledger updates are committed on `parity-loop-run2` and merged into main regularly.

## So far

- **Verify:** 73 of the 74 merged command fixes re-check clean on main. `toolbar:SketchImportSVG`
  still differs, and #40 was closed without merging, so it is back to `mismatch`.
- **Driver probes:** Offset Face and body Move/Copy mismatches found. Fixer PRs #123 (closed: main
  already had the fix), #124 (merged), #126.
- **UI discovery:** about 35 new behaviours. The finds:
  - **Inert menu items:** 79 toolbar menu items in FissionOxide do nothing. #125 wired the ones
    whose engine command exists (Sketch Move/Copy, Sketch Scale, Project To Surface, Align,
    Polygon constraint, Create Base Feature, the Construction filter). UCS, Duplicate With Joints
    and Intersect need engine commands first.
  - **Assemblies:** joint glyphs, a short joint context menu, and the browser structure
    (occurrences as `Name:1`, bodies listed twice, no Relationships folder).
  - **Input:** wheel zoom runs the opposite way to Fusion's default; double middle-click doesn't
    fit; no copy/paste; Space doesn't repeat the last command.
  - **Dialogs:** manipulators exist only on a few dialogs and never when editing a feature.
    Sketch Fillet uses a docked dialog rather than working in the canvas. Sketch Mirror and
    patterns pick their references from dropdowns. The SURFACE and SHEET METAL dialogs are
    thinner than Fusion's, and Ruled is a different feature.
  - **Errors:** no Review Warning / Error window for failed features.
  - **Other areas:** Preferences cover a fraction of Fusion's settings. The Manufacture
    workspace has one tab against Fusion's six, and its op names are out of date.
  - **Panel order:** corrected. Fusion's Part Design orders the panels the same as FissionOxide;
    only Hybrid designs put ASSEMBLE after MODIFY.
- **Blocked:** the Drawing workspace UI. Fusion only makes drawings from a saved design, and the
  loop never saves in Fusion.
- **Fusion crash:** at 14:06 Fusion crashed during a probe. On restart FoxBridge loaded twice:
  once through the AddIns junction and once from the repo path, both set to run on startup. The
  repo-path copy no longer runs on startup.
