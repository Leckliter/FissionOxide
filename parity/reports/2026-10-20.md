## How it ran

- **03:04–03:18:** preflight, then the ViewCube and navigation-bar probes. The run stopped when
  an action was declined and resumed at 07:56.
- **From 08:00:** the work split into three roles so nothing waited on anything else:
  - **Prober:** this session holds the screen.
  - **Fixers:** one cloud or worktree agent per batch.
  - **Merger:** first a local agent; from about 10:15 the driver session's integration gate.
- **Fix work:** 21 batches across three waves, plus one test-isolation fix. That made 21 PRs, all
  merged to `main` (now at `8a0ba726`): #100–#117, #119, #120 and #122. #122 replaced #118, whose
  second copy of the shortcut table clashed with #103's.
- **Checking:** three installers (`dist/FissionOxide-0.1.1-parity{1,2,3}-x64-setup.exe`). Each
  merged fix was re-probed in the installed app before being marked verified.

## Notable fixes, all verified in the app

- **Sketch:**
  - Heads-up Tab works: `40 Tab 20 Enter` gives a 40 × 20 rectangle with both dimensions.
  - Fully constrained curves draw black.
  - Inference guides snap to aligned points.
  - Line drags out a tangent arc.
  - Trim previews the piece it will remove in red.
  - Offset follows the cursor.
  - P runs Project.
- **ViewCube and camera:**
  - Edge and corner hot spots, with a hover highlight on just that spot.
  - Roll and step arrows.
  - Fusion's cube menu.
  - The cube fades when idle and has a compass ring.
  - Every camera move animates.
- **Canvas:**
  - Double-clicking an edge selects its loop.
  - The marking menu's list stays off the ring.
  - Move has a triad manipulator, with Fusion's move types.
- **Dialogs:**
  - Single-click hole placement, with the hole diagram.
  - The pattern dialog.
  - Shell direction.
  - Offset Plane takes a picked face.
- **Timeline and browser:**
  - Drag the history marker; drag features to reorder.
  - Rename in place; fuller context menus for bodies, sketches, planes, components and the
    canvas.
- **App:**
  - Per-design units (mm, cm, m, in, ft).
  - A Change Parameters dialog with model parameters.
  - Preferences with navigation presets.
  - Rich tooltips, pin to toolbar and custom shortcuts.
  - Measure with precision and copy; named views; an appearance panel with drag-and-drop;
    an isolate banner.
  - Escape closes menus; a new Help menu and Keyboard Shortcuts window.
- **Bugs:**
  - A file passed to the running app now draws immediately.
  - Tests no longer write empty "Untitled" designs into the real hub. The cause was the engine
    test `every_listed_command_is_handled`, which ran `hub.save` against `%APPDATA%`. The 245
    junk items already in the hub are still there, for the user to clear.

## Notes for the next run

- **Installing a new build** into `C:\Program Files\FissionOxide` needs an admin prompt that only
  the user can approve, so each re-check round waits on them. A per-user installer would remove
  that wait.
- **Focus:** Windows' TextInputHost and the desktop shell often take focus between actions. The
  scratch helper `focus_fox.ps1` clicks FissionOxide's own canvas to get it back. While Chrome
  Remote Desktop is connected, its sharing bar blocks all input.
- **Modifier keys:** the desktop-control tool sends a modifier in the same frame as the click,
  and egui misses it. Hold the key with `keybd_event` instead.
- **Agent builds** need `FOX_OCCT_DIR` set to the main checkout's `target/OCCT`, plus
  `cargo test --no-fail-fast` and a temp `FOX_DATA_DIR`.
