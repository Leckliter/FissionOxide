# MESH tab (prober 14, 2026-10-22)

Fusion (Personal licence, document "Untitled*(1)", Part Design, inches) and FissionOxide (built from
`main` at `25d185b8`, a fresh unsaved design, mm) side by side. Both apps inserted
`tests/reference/464-stl-millimeter/lprism.stl` (an L-prism, 12 triangles) with MESH > CREATE >
Insert Mesh; Fusion then opened every MESH command with the mesh selected, FissionOxide every command
that has a dialog.

## The main finding

FissionOxide has no mesh body. Its importer turns STL/OBJ/3MF/PLY into faceted solids
(`crates/exchange/src/lib.rs:98`), so the inserted file is "Body1" with the solid icon, picks single
planar faces and gets the solid face menus. Fusion keeps "lprism" as a mesh body (mesh icon, picked
whole, its own menus, mesh-only commands). Most other rows follow from that; batch
`ui-mesh-body-and-insert` is the base the other three build on.

## Matches

- `ui:mesh:menu-lists`: CREATE, PREPARE, MODIFY and EXPORT dropdowns have the same entries, order,
  separators and shortcuts.
- `ui:mesh:tooltip-texts`: Insert Mesh's tooltip text is Fusion's word for word.

## Differences

P1
- `ui:mesh:mesh-body-kind`: no mesh body kind (above).
- `ui:mesh:insert-mesh-dialog`: Fusion's INSERT MESH dialog (Unit Type, Flip Up Direction, Center,
  Move To Ground, Numerical Inputs, Reset, a move/rotate triad) is missing; FissionOxide inserts at once.
- `ui:mesh:body-context-menu`: mesh body menus (Edit Feature, Flat Shaded, Direct Edit; no Create
  Components from Bodies) vs FissionOxide's solid body and face menus.
- `ui:mesh:reduce-dialog`: Fusion's Type / Remesh Type / Proportion vs "Keep (fraction)"; FissionOxide's
  preview flattens the prism.
- `ui:mesh:plane-cut-dialog`: FissionOxide opens SPLIT BODY; Fusion's PLANE CUT has Cut Plane, Flip,
  Type, Fill Type, numerical inputs, handles and a red preview of the removed part.
- `ui:mesh:convert-mesh-dialog`: Operation and Method rows missing; Fusion hides the mesh and adds a new
  solid ("Convert Mesh1"), FissionOxide converts in place ("ConvertMesh1").
- `ui:mesh:remesh-dialog`, `ui:mesh:tessellate-dialog`, `ui:mesh:direct-edit-environment` (the
  DIRECT MESH EDITING tab with the Mesh Selection Palette): stubs in FissionOxide.

P2
- `ui:mesh:insert-timeline-item` ("Base Mesh Feature1" vs "Import1"), `ui:mesh:open-mesh-warning`
  ("Mesh is not closed." on the row after an unfilled Plane Cut), `ui:mesh:smooth-dialog` (Smoothness
  slider vs Passes; FissionOxide's preview shrinks the body), `ui:mesh:ribbon-quick-buttons` (Fusion's
  MODIFY panel shows only Remesh and Reduce; plain yellow-box icons), and the stubs
  `ui:mesh:shell-dialog`, `ui:mesh:combine-dialog`, `ui:mesh:separate-dialog`,
  `ui:mesh:scale-mesh-dialog`, `ui:mesh:repair-dialog`, `ui:mesh:face-groups-dialogs`,
  `ui:mesh:section-sketch-dialog`.

Common to every Fusion mesh dialog: an "i" info icon at the lower left, Preview unticked; FissionOxide's
mesh forms tick Preview. Fusion's dialogs dock at the upper right under the ViewCube; FissionOxide's
float lower (already covered by the dialog docking keys).
